# 课程详情接口分析

基于 `webvpn.zjnu.edu.cn_2026_06_05_19_50_05.har` 抓包，分析教务系统课程详情相关的三个接口。

## 1. 课程基本信息 `common_cxKcxxModel`

### 请求

```
POST /jwglxt/xkgl/common_cxKcxxModel.html?gnmkdm=N253512
Content-Type: application/x-www-form-urlencoded;charset=UTF-8

kch_id=000000X111A104
```

| 参数 | 说明 |
|------|------|
| `kch_id` | 课程号（如 `000000X111A104`） |

URL 的 `gnmkdm=N253512` 为功能模块代码（选课模块固定值），可带 `&time=` 时间戳。

### 响应

HTML 页面，`<table>` 中包含以下字段（每行两对 label-value）：

| 字段 | 示例值 |
|------|--------|
| 课程代码 | `000000X111A104` |
| 课程名称 | `双创教育—TRIZ创新方法` |
| 课程英文名称 | `Innovative and Entrepreneurial Education - TRIZ Innovation Method` |
| 开课学院 | `创业中心` |
| 学分 | `1.0（仅供参考，以业务实际学分为准）` |
| 课程类别 | `【新】公共基础课程` |
| 课程归属 | `【新】理论课程` |
| 开课学期 | （通常为空） |
| 成绩录入级别 | `百分制` |
| 可否申请免听 | `不可以` |
| 统一安排补考否 | `是` |
| 可否快速选课 | `可以` |
| 课程启用年级 | `2024` |
| 是否是实践课 | `否` |
| 是否可补考 | `可以` |
| 面向对象 | （通常为空） |
| 周学时 | `理论(1.0)` |
| 预修课 | （通常为空） |
| 课程简介 | （通常为空） |
| 教学大纲 | （通常为空） |

页面末尾还有一个 jqGrid 请求 `/xkgl/common_cxKklsxx.html`，查询该课程历年开课的选课人数、平均分、及格率、优秀率（`postData: {kch_id}`）。此接口未在抓包中单独出现，可能在页面加载时自动触发但未被 HAR 记录。

### 解析方式

HTML table 的 `<tr>` 结构稳定，每行两对 `<td>`（label / value），用正则或 HTML 解析器提取。注意 label 后有 HTML 注释（如 `<!-- 课程代码 -->`），value 可能为空或嵌套 `<div>`。

## 2. 教师详情 `common_cxJsxxModel`

### 请求

```
POST /jwglxt/xkgl/common_cxJsxxModel.html?gnmkdm=N253512
Content-Type: application/x-www-form-urlencoded;charset=UTF-8

jgh_id=20164148&kch_id=000000X111A107
```

| 参数 | 说明 |
|------|------|
| `jgh_id` | 教职工号（从教学班 `jsxx` 字段解析，格式 `工号/姓名/职称`） |
| `kch_id` | 课程号 |

### 响应

HTML 页面，`<label>` + `<div>` 组合，字段如下：

| 字段 | 示例值 |
|------|--------|
| 教师姓名 | `陈森亮` |
| 姓名拼音 | `Chen Senliang` |
| 性别 | `男` |
| 所在单位 | （可能为空） |
| 最高学历 | （可能为空） |
| 电子邮箱 | （可能为空） |
| 研究方向 | （可能为空） |
| 科室名称 | （可能为空） |
| 职称 | `讲师` |
| 教师简介 | （可能为空） |

## 3. 教材信息 `tjxkyzb_cxJcxxList`

### 请求

```
POST /jwglxt/xsxk/tjxkyzb_cxJcxxList.html?gnmkdm=N253512
Content-Type: application/x-www-form-urlencoded;charset=UTF-8

jxb_id=5182BEAAA4CD5099E0639F46010A969B
```

| 参数 | 说明 |
|------|------|
| `jxb_id` | 教学班 ID |

### 响应

HTML 页面，内容通常为 `无教材信息` 或包含教材列表的表格。本次抓包中均为"无教材信息"。

## 4. 教学班列表中的教师字段

教学班列表 API (`zzxkyzbjk_cxJxbWithKchZzxkYzb`) 返回的每个教学班 JSON 中，`jsxx` 字段格式为：

```
"jsxx": "20164148/陈森亮/讲师"
```

即 `工号/姓名/职称`，可直接解析出 `jgh_id` 用于查询教师详情。

## 5. 前端触发方式（原始教务系统）

原始教务系统中，用户在课程列表点击课程名称时弹出 iframe 加载 `common_cxKcxxModel.html`，点击教师名称时弹出 `common_cxJsxxModel.html`。这些都是 Bootstrap 模态框 + iframe 的传统方式。
