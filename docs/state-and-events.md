# 状态职责与请求边界

本文档约定 JWXT Web UI 中前端、后端和上游教务系统之间的状态职责与数据交互方式。

## 总原则

- 后端是业务状态源，前端只是 Web UI 和后端状态快照的展示缓存。
- 前端不应为了“查看状态”触发上游教务请求。
- 普通 GET 默认读取后端本地缓存；只有明确 `refresh=1` 或业务动作要求时才请求上游教务。
- 抢课调度、表达式解释、扫描范围、候选教学班、选课提交等业务逻辑必须由后端负责。
- SSE 只用于后端状态变化通知，不用于触发上游刷新。

## 需要直接请求上游教务的操作

- 登录 / 重新登录。
- 手动刷新大类列表。
- 加载某大类课程分页。
- 加载某课程教学班详情。
- 用户明确刷新某课程教学班详情。
- 抢课 tick 刷新候选课程的教学班余量。
- 选课 / 退课提交。
- 选课 / 退课 / 抢课成功后的课表刷新。
- 用户明确点击“刷新已选课程”。
- 用户明确点击“刷新学业情况”。
- 首次打开学业情况且后端无缓存。
- 导出所有课程时补齐未加载的课程和教学班数据。

## 不应直接请求上游教务的操作

- 前端订阅或查看抢课任务状态。
- 打开抢课任务详情。
- 打开教学班详情弹窗。
- 切换课程树显示过滤条件。
- 本地搜索已加载课程 / 教学班。
- 切换 tab。
- 抢课表达式前端语法校验。
- 查看日志、活动、调试 JSON。
- 展开已经加载过的大类或课程。
- 展示课程树、课表、学业情况的已有内容。

## 后端维护的状态

- 登录会话、cookies、SSL 设置。
- 大类列表缓存。
- 已加载课程分页缓存。
- 已加载教学班详情缓存。
- 当前个人课表缓存。
- 学业情况缓存。
- 抢课任务列表、任务状态、候选课程 / 教学班、tick 统计、任务事件。
- 请求日志和活动事件。
- 课程树快照。
- 所有影响选课结果的业务判断：表达式解析、扫描范围、候选生成、冲突判断、容量判断、选课提交。

## 前端维护的状态

- UI 展示状态：当前 tab、展开 / 折叠、选中周次和格子、弹窗、浮动菜单、侧栏折叠。
- 表单和编辑器输入：抢课表达式、启动配置、搜索关键词、过滤开关。
- 后端状态快照的展示缓存：课程树、课表、学业情况、抢课任务。
- 前端派生展示：本地搜索、灰色显示冲突、隐藏超学分课程、表格和树的分组渲染、调试 JSON 展示。

## 普通请求

普通请求用于命令和一次性缓存读取。

- 登录、设置、地址测速。
- bootstrap 初始状态。
- 课程树 / 课表 / 学业情况缓存读取。
- 显式刷新已选课程、学业情况、大类列表、教学班详情。
- 展开大类加载课程分页。
- 展开课程加载教学班。
- 抢课预览、加载预览缺失数据。
- 创建、启动、停止抢课任务。
- 手动选课 / 退课。
- 导出数据。
- 查看历史日志详情。

## SSE

SSE 用于后端状态变化推送。

- 日志流。
- 抢课任务状态变化：tick、进度、成功 / 失败 / 超时、最近错误、最近结果、tick debug、事件列表。
- 抢课成功后的后端状态快照通知：课表缓存更新、课程树快照更新。
- 长任务进度：加载缺失数据、导出所有课程、批量拉取课程 / 教学班。
- 会话状态变化：登录过期、上游请求异常、调度器异常。

## 同步方式

- 小数据可以 SSE 直接推完整 payload，例如日志行、任务摘要、活动行。
- 大数据优先推版本号或轻量快照；前端需要时再普通请求读取后端缓存，普通缓存读取不能请求上游教务。
- 抢课成功应由后端刷新本地课表缓存，再通过 SSE 推送任务更新和缓存快照 / 版本。

## 禁止模式

- 前端定时轮询抢课任务。
- 前端收到事件后无条件请求 `/api/timetable?refresh=1`。
- SSE 事件触发上游刷新。
- 高频 SSE 推送大 JSON。
- 前端把业务状态作为真实来源自行推断。
