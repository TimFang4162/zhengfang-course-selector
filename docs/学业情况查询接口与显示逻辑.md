# 学业情况查询接口与显示逻辑

分析来源：`docs/webvpn.zjnu.edu.cn_2026_06_04_12_41_38.har`。

## 页面入口

- 功能名称：学生学业情况查询
- 模块代码：`N105515`
- 入口 URL：`/jwglxt/xsxy/xsxyqk_cxXsxyqkIndex.html?gnmkdm=N105515&layout=default`
- 页面脚本：`/jwglxt/js/comp/jwglxt/xjgl/xyqk/cxXsxyqkIndex.js`

入口页面由服务端直接输出学分要求节点树。页面 HTML 中同时包含后续明细请求需要的隐藏字段：`xh_id`、`cjlrxn`、`cjlrxq`、`bkcjlrxn`、`bkcjlrxq`、`xscjcxkz`、`cjcxkzzt`、`cjztkz`、`cjzt`。

## 课程明细接口

### 教学计划课程

- 方法：`POST`
- URL：`/jwglxt/xsxy/xsxyqk_cxJxzxjhxfyqKcxx.html?gnmkdm=N105515`
- 常规参数：`fromXh_id`、`xfyqjd_id`、`xh_id`
- 特殊节点 `qtkcxfyq`、`cxcyqkxfyq` 还需要成绩控制参数：`cjlrxn`、`cjlrxq`、`bkcjlrxn`、`bkcjlrxq`、`xscjcxkz`、`cjcxkzzt`、`cjztkz`、`cjzt`

### 非教学计划课程

- 方法：`POST`
- URL：`/jwglxt/xsxy/xsxyqk_cxJxzxjhxfyqFKcxx.html?gnmkdm=N105515`
- 参数：`fromXh_id`、`xfyqjd_id`、`xh_id`

页面脚本按节点属性 `jdkcsx` 决定接口：`jdkcsx == '1'` 使用教学计划课程接口，否则使用非教学计划课程接口。特殊节点 `qtkcxfyq`、`cxcyqkxfyq` 固定走教学计划课程接口并附加成绩控制参数。

## 响应字段

两个明细接口均返回 JSON 数组。常见字段如下：

- `KCH_ID` / `KCH`：课程 ID / 课程号
- `KCMC`：课程名称
- `KCYWMC`：英文名称
- `XF`：学分
- `XDZT`：修读状态，抓包中可见 `1`、`3`、`4`
- `CJ` / `MAXCJ`：成绩 / 最大成绩
- `JD`：绩点
- `XNMC` / `XQMMC`：成绩学年 / 学期
- `JYXDXNMC` / `JYXDXQMC`：建议修读学年 / 学期
- `KCLBMC`：课程类别
- `KCXZMC`：课程性质
- `KCGSMC`：课程归属或课程形式
- `XSXXXX`：学时信息
- `SFJHKC`：是否计划课程

当前应用按教务系统 `getXdzt` 逻辑将 `XDZT` 归一化为：`1=在修`、`2=未过`、`3=未修`、`4/21=已修`、`5-9=课程替代/认定类`、`10=预警不审核`。未知状态保留原值。

## 节点状态

入口页面的每个学分要求节点包含 `yxxf`、`yqzdxf`、`sftg` 和 `thzt`。当前应用与教务系统前端保持一致：

- `yxxf < yqzdxf`：学分未满
- `yxxf >= yqzdxf` 且 `sftg == 0`：节点未过
- `yxxf == yqzdxf` 且 `sftg == 1`：学分已满
- `yxxf > yqzdxf` 且 `sftg == 1`：学分超出
- `thzt` 包含 `1`：校外课程替代节点
- `thzt` 包含 `2`：校内课程替代节点
- `thzt` 包含 `3`：节点替代

## 应用实现

前端只作为 Web UI 使用。刷新页面时先请求 `/api/bootstrap`，若后端仍持有登录态，则直接复用后端内存中的 JWXT session；只有后端未登录、服务重启或登录态失效时才显示登录框。

后端新增 `/api/academic-status`：

- 默认返回缓存数据。
- `?refresh=1` 重新请求教务系统。
- 所有教务系统请求均由 Python 后端发起，前端只请求本地 `/api/academic-status`。
- 响应包含 `updatedAt`、`fromCache`、`cacheStatus`，用于标识后端缓存更新时间和本次缓存状态。
- `cacheStatus=miss` 表示后端首次未命中缓存并完成拉取；`hit` 表示后端缓存命中；`refresh` 表示用户显式刷新后缓存已更新。
- 普通课程树状态查询不会清空学业情况缓存；显式刷新课程列表或重新登录会清空相关业务缓存。
- 先请求入口页面，解析节点树、隐藏参数和根节点学分汇总。
- 再按末级节点拉取课程明细，并将字段归一化后挂到对应节点。

前端新增 `学业情况` tab：

- 第一次切换到 tab 时懒加载 `/api/academic-status`。
- 点击刷新按钮时请求 `/api/academic-status?refresh=1`。
- 使用 VS Code 风格暗色树表展示：节点行显示名称、已获/要求学分、达标状态和通过课程数；节点展开后显示课程明细表。
- 已通过课程用绿色左边框提示，未通过课程用红色左边框提示。

## 课程详情弹窗

分析来源：`docs/10.1.70.170_2026_06_09_14_49_53.har`。

点击学业情况课程表中的课程名称时，弹出课程基本信息详情。

### 接口

- 方法：`POST`
- URL：`/jwglxt/jxjhgl/common_cxKcJbxx.html?id={kchId}&time={timestamp}&gnmkdm=N105515`
- Content-Type：空（URL 参数查询）
- 请求体：`{}`
- 响应：`text/html`（约 8KB）

### 响应结构

返回 HTML 片段，包含三个选项卡：

1. **基础信息**（`#home`）
   - 课程代码 / 课程中文名称 / 英文名称
   - 开课部门 / 学分 / 课程类别 / 课程归属 / 课程负责人
   - 是否实践课标记 / 实践周数
   - 课程学时 + 分项学时表（理论 / 术科 / 实践 / 实验）

2. **课程简介和教学大纲**（`#profile`）
   - 中文课程简介 / 英文课程简介
   - 中文教学大纲 / 英文教学大纲

3. **辅助信息**（`#info`）
   - 预修要求 / 成绩录入级别 / 申请免听标记 / 统一安排补考标记
   - 快速选课标记 / 课程启用年级 / 面向对象 / 备注

### 应用 API

- 方法：`GET`
- URL：`/api/academic-course-detail?kch_id={kchId}`
- 响应：后端解析后的 JSON 结构

### 前端实现

- `academic.js`：`loadAcademicCourseDetail(kchId)` 调用 API，存入 `state.academicCourseDetail`
- `AcademicView.jsx`：课程名渲染为 `<button class="link-button">`，点击触发加载；详情面板在课程表下方内联展示，使用 `debug-grid` 布局显示所有字段 + 学时分项子表
